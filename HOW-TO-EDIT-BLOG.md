# How to Edit Your Blog

## 📝 Editing Blog Articles

Your blog is located in the `blog.html` file. You can edit it directly without any technical knowledge!

### To Add a New Blog Article:

1. **Go to GitHub**: https://github.com/ajay3varada-lang/butterflybloom-website
2. **Click on** `blog.html`
3. **Click the pencil icon** (Edit this file)
4. **Copy this template** and paste it before the closing `</div>` tag (before `</div>` that closes `blog-container`):

```html
<!-- New Article -->
<article>
    <div class="article-meta">
        <span>📅 YOUR DATE HERE</span>
        <span>👤 Butterfly Bloom CDC</span>
        <span>⏱️ X min read</span>
    </div>
    <h2>Your Article Title Here</h2>
    
    <p>Your introduction paragraph here...</p>

    <h3>Section Heading</h3>
    <p>Your content here...</p>

    <h3>Another Section</h3>
    <ul>
        <li>Bullet point 1</li>
        <li>Bullet point 2</li>
        <li>Bullet point 3</li>
    </ul>

    <div class="highlight-box">
        <p><strong>Important:</strong> Your highlighted message here</p>
    </div>

    <div class="cta-box">
        <h3>Call to Action Title</h3>
        <p>Your call to action message</p>
        <a href="index.html#contact" class="cta-button">Button Text</a>
    </div>
</article>
```

5. **Replace** the placeholder text with your content
6. **Scroll down** and click **"Commit changes"**
7. **Wait 2 minutes** for Vercel to deploy

---

## ✏️ Editing Existing Articles

1. Find the article you want to edit in `blog.html`
2. Change the text between the HTML tags
3. Commit your changes
4. Wait for deployment

---

## 🎨 Formatting Guide

### Headings:
```html
<h2>Main Article Title</h2>
<h3>Section Heading</h3>
```

### Paragraphs:
```html
<p>Your paragraph text here.</p>
```

### Bullet Lists:
```html
<ul>
    <li>First point</li>
    <li>Second point</li>
</ul>
```

### Numbered Lists:
```html
<ol>
    <li>First step</li>
    <li>Second step</li>
</ol>
```

### Bold Text:
```html
<strong>Bold text here</strong>
```

### Highlight Box (Purple background):
```html
<div class="highlight-box">
    <p><strong>Important:</strong> Your message</p>
</div>
```

### Call-to-Action Box:
```html
<div class="cta-box">
    <h3>Your CTA Title</h3>
    <p>Your message</p>
    <a href="index.html#contact" class="cta-button">Button Text</a>
</div>
```

## 🚀 Quick Tips

1. **Always test** your changes by visiting the blog page after deployment
2. **Keep articles between 800-1500 words** for best engagement
3. **Use headings** to break up content
4. **Add bullet points** for easy scanning
5. **Include CTAs** to encourage bookings
6. **Update dates** when you publish new articles

---

## 🆘 Need Help?

If you make a mistake:
1. Go to the file history
2. Click "Revert" on the last working version
3. Or ask for help to restore it

## 📊 SEO Tips for Blog Articles

1. **Use keywords** like "child development", "speech therapy", "Visakhapatnam"
2. **Write clear titles** that describe the content
3. **Keep paragraphs short** (2-3 sentences)
4. **Use subheadings** every 200-300 words
5. **Add internal links** to your services
6. **Include CTAs** in every article
